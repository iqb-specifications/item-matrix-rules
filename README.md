**missing-map** defines rules for translateing variable response status into item missing values.

Read more:

* [All specifications of IQB](https://iqb-specifications.github.io/) (German only)
* [Learn about TBA](https://iqb-berlin.github.io/tba-info/) (German only)

For a human readable version of the spec [see here](https://iqb-specifications.github.io/missing-map). For validation purposes (get json schema directly) use this link:

```
    https://w3id.org/iqb/spec/missing-map/<major>.<minor>
```
